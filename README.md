 Grounded in source? ──Yes──► Answer + Citations
     │
     No
     ▼
 Fallback / Clarify   ◄── I'd rather say "I don't know" than hallucinate

**Agent Reasoning Loop — plans before it acts**

```
 Goal Received
     │
     ▼
┌──► Plan Next Step
│         │
│         ▼
│    Select Tool ──► Execute Action
│                          │
│                          ▼
│                   Goal Complete?
│                     │        │
└─────────No──────────┘       Yes
                                │
                                ▼
                         Return Result
```
